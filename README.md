# Кредитний калькулятор — патерн «Стратегія»

Лабораторна робота на Windows Forms (.NET), що демонструє патерн **Strategy**.

## Як працює

Користувач вводить суму кредиту, кількість місяців і обирає банк. Калькулятор (`CreditCalculator`) рахує переплату за стратегією обраного банку:

| Банк | Розрахунок переплати |
|------|----------------------|
| PrivatBank | 3 % на місяць |
| MonoBank | 2,5 % на місяць + 200 грн комісії |
| OschadBank | 2,8 % на місяць |

Кожен банк — окремий клас, що реалізує `ICreditStrategy`. Відсотки умовні, навчальні.

## Запуск

Відкрийте `lb122.sln` у Visual Studio і натисніть F5.
